## Fluxo  de trabalho Git local

1. git checkou -b <nova-branch>
2. cria ou atualiza arquivos
3. git status
4. git add .
5. git status
6. git commit -m "minha mensagem"
7. git checkout main
8. git merge nova_branch

## Fluxo de trabalho GitHub <> Local (projeto Open-source)
1. Fork do projeto para o seu próprio projeto gihub
2. git clone <endereço do projeto>
3. git checkout -b <nova_branch>
4. alterações de arquivos
5. git status
6. git add *arquivos*
7. git status
8. git commit -m "minha mensagem"
9. git push origin <nova_branc>
10. abrir Pull Request no GitHub da branch fork para a main do peojeto original
11. excluir <nova_branch> origin
12. git checkout main
13. git branch -D <nova_branch>
